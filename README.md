# yingxuzpa-notes

Linux · Networking · TypeScript

给自己省点事的小工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/yingxuzpa-notes.git
cd yingxuzpa-notes
cargo build --release
```
